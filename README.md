# SECTOR-5B

Game bắn xe tăng và hiệp đồng binh chủng 3D chạy thẳng trên trình duyệt. Toàn bộ game chỉ nằm trong đúng 1 file `.html` duy nhất, không dùng bất kỳ file hình ảnh, âm thanh hay mô hình tải sẵn nào từ bên ngoài.

[Chơi thử trực tiếp (Live Demo)](#)

## Đôi lời về dự án

Mình làm kỹ thuật mà thật sự không rành về code hay lập trình web.

Mà mình cũng ưng mấy game như War Thunder, nên có bắt chước thử làm 1 cái game

Cảm ơn Gehihi 4 Argon nhiều, không biết gì vẫn ra được con game ni :]]]
